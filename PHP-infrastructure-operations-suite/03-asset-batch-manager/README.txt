Asset Batch and Transfer Manager

Idea:

This system groups validated equipment into a reusable asset batch. A batch has a short code, an owner, a lifecycle, notes, and a controlled list of assets.

How a business could use it:

- Prepare equipment for a shipment, installation, repair, warehouse move, or disposal review.
- Add assets by scanning an ID, entering a serial number, or pasting a list.
- Validate every item against the business inventory source.
- Complete and lock a batch when it is ready for another team or system.
- Copy a completed batch into a new revision when work must be repeated.
- Import a completed batch into another workflow, such as a site audit.
- Print the batch or download it as CSV.

The public demo uses synthetic assets and temporary session storage.
