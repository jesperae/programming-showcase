Reusable Operations UI and Reporting Toolkit

Idea:

Small business applications repeatedly need the same request handling, loading messages, dialogs, searchable controls, tables, and exports. This toolkit keeps those behaviors reusable and consistent.

How a business could use it:

- Connect PHP actions to JavaScript with predictable JSON responses.
- Show the same loading, success, and error behavior across tools.
- Reuse alert, confirmation, prompt, and choice dialogs.
- Add searchable selectors, tooltips, and URL options to compact forms.
- Build a print-ready report and CSV from the same data definition.
- Give several internal applications a shared visual style.
