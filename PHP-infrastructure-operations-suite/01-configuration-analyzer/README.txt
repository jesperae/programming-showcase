Multi-Vendor Network Configuration Analyzer

Idea:

Device configurations can be difficult to review quickly. This system reads several generic configuration formats and turns permitted network ranges into a consistent list with the rule that allowed each range.

How a business could use it:

- Review access rules without reading an entire configuration file.
- Filter results to one rule or hide rules that are not relevant.
- Find overlapping network ranges.
- Check whether an address is already covered by a permitted range.
- Copy normalized results into a ticket, audit, or change review.

The included devices, formats, configurations, and networks are synthetic.
